# Spotlight Admin UX

The admin is an operations workbench for finding a business, understanding its state, and taking the next action quickly.

## Navigation

- Desktop uses a stable grouped sidebar.
- Mobile uses one grouped section selector; do not recreate a horizontally scrolling menu.
- Keep business editing inside the business context. Global tables browse and select.

## Business lists

- Desktop rows expose one primary action: **Manage**.
- Secondary and destructive actions live in the overflow menu.
- Mobile uses task-oriented cards, not a compressed desktop table.
- Identity, location, and status appear before actions. Internal IDs remain secondary.

## Business editor

- Primary sections are Details, Hours, Media, Social Links, Menu, Reviews, and Inbox.
- Advanced tools are progressively disclosed under **More tools**.
- Mobile uses a grouped section selector with a minimum 44px touch target.
- Promotional content must not push editing controls below a long feature wall.

## States and safety

- Loading, empty, error, and permission states explain the next available action.
- Delete remains visually separated and requires confirmation.
- Search and status filters should preserve the operator's current context whenever possible.
